# 前端渲染约定

> 只讲「怎么画才不卡」。界面该从哪拿数据、什么时候重画，见 `../smart-wine-cooler-wiki/UI`。

---

## 1. 重画的代价取决于改了什么

浏览器把一次更新拆成五步：

```
JavaScript → Style → Layout → Paint → Composite
```

- **只触发合成**（位置变换、透明度）→ 最便宜
- **触发绘制**（阴影、模糊、渐变）→ 贵
- **触发布局**（尺寸、位置、节点增删）→ 最贵

---

## 2. 触屏设备上禁止的三样

手机、平板的图形能力弱，下面三样会让滚动和弹窗明显掉帧。**触屏设备一律不开**：

| 禁止 | 为什么 |
| --- | --- |
| 吸顶栏用实时模糊 | 滚动时每一帧都要重算一次全宽模糊 |
| 全屏常驻的循环动画 | 页面永远处于「有动画在跑」，持续占着合成线程 |
| 全屏滤镜噪点 | 每次重绘都要重新光栅化整屏纹理 |

**判据**：这个视觉效果是否只在**内容静止时**才看得见？是——那它在滚动和弹窗时就是纯负担。

---

## 3. 弹窗必须挡住背景滚动

弹窗打开时，滚动必须限制在弹窗内。背景页跟着滚会触发整页重绘，在移动端表现为闪烁。

**判据**：弹窗打开后，手指滚到底再继续滚，背景页不能动。

---

## 4. 术语对照

| 我们这里叫 | 行业通用叫法 |
| --- | --- |
| 滚动时画面撕裂 | Jank（掉帧） |
| 弹窗打开时页面跳一下 | CLS（累积布局偏移） |
| 背景页跟着弹窗一起滚 | Scroll Chaining（滚动穿透） |
