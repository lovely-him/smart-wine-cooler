# 采集设备与节点

> 板子上怎么找到摄像头。产品的设计约束（只认 by-id、分辨率与朝向属于摄像头）见 `../smart-wine-cooler-wiki/BLD §2`。

---

## 1. 只认 by-id，不认 `/dev/videoNN`

板子上除 USB 摄像头外还有一批芯片内部节点，节点号又会随插拔与重启变化。所以：

- 候选列表取 `/dev/v4l/by-id/` 下的 USB 摄像头
- 取 `-video-index0` 那一条
- **`-video-index1` 是元数据节点**：能打开，但永远不出帧——选中它表现为「能开流却拿不到画面」

---

## 2. 板上会混进来的节点

以下不是摄像头，出现在候选里要过滤掉：

- `rkisp`（ISP 处理节点）
- `hdmirx`（HDMI 输入）

判断依据是路径在 `/dev/v4l/by-id/` 下且带 USB 描述，而不是靠节点名白名单——白名单会随内核版本变。

---

## 3. 其它

- 打开设备时校验像素格式，校验失败直接报「打不开」，不要等抓帧超时
- 超时要短：设备被占用时，等下去只会拖住整次观察
